## Searchable official text

LDAUL = [integer array]
Default: LDAUL = NTYP*2

Description: LDAUL specifies the [math]\displaystyle{ l }[/math]-quantum number for which the on-site interaction is added.

For LDAUL=-1 no on-site interaction is added.

Mind: one has to specify one number for each atomic species.
