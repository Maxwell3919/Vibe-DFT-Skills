1    Introduction
This guide covers the usage of QE-emacs-modes package (aka QE-modes): an open-source col-
lection of Emacs major-modes for making the editing of Quantum ESPRESSO (QE) input
files somewhat easier and more comfortable with Emacs editor. The package provides syntax
highlighting (see Figure 1), basic auto-indentation, and several utility commands.
