# Orchestration workspace and taskbook route

Use `docs/calculation-workspace-and-taskbook.md` as the repository-wide
operational protocol. Before a calculation side effect, preserve the user's
explicit `off`, `silent-update`, or `milestone-review` choice alongside the
immutable workflow plan.

The taskbook is a revisioned progress aid. It does not replace a workflow plan,
execution request, authorization, run manifest, or scientific decision.
Structure, input, result, and figure milestones must name stable hashed
artifacts. In review mode, pause on `pending-review`; in silent mode, continue
only within the already agreed route and authority. This development Skill may
plan the layout but does not initialize or authenticate a production taskbook.
