# LASP documentary role and handoff model

Current work stops before operational implementation. Roles are arranged to prevent a capability paper or discovered binary from becoming guessed syntax or unauthorized execution.

| Role | Current responsibility | Explicit stop condition |
|---|---|---|
| scientific planner | record project intent and acceptance rules | no keyword mapping is claimed |
| documentation acquirer | obtain authorized version-matched manual and terms | discovery links alone are insufficient |
| source/legal reviewer | verify completeness, version, access and redistribution scope | unknown terms remain blocking |
| future parser implementer | design syntax/output/restart parsers from reviewed sources | no analogy to another engine/version |
| fixture reviewer | establish legal origin and independent expected values | opaque placeholders are not LASP artifacts |
| future execution authorizer | verify licensed binary/environment and exact authority | this candidate grants none |
| scientific reviewer | assess eventual method and evidence | generic extxyz integrity proves no LASP claim |

Every documentary handoff retains exact upstream raw-byte SHA-256 values, descriptive self-fingerprints, artifact hashes, evidence-gap IDs, `no_positive_claim`, false promotion/execution authorization, `unsigned-candidate-output`, and a minimum next action. Filling a gap requires a new review record; an agent assertion or self-fingerprint cannot close it. Only an external trusted manifest or signature can authenticate report bytes as evidence.
