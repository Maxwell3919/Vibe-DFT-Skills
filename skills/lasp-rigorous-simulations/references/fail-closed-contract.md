# LASP fail-closed documentary contract

The public LASP Hub establishes a 3.7.3 Linux/Intel baseline, `Src/lasp`, and direct/MPI launcher examples, but this candidate has no retained authorized version-matched input/output/restart specification, exact build matrix, or complete license terms. It therefore validates plan completeness and artifact integrity only. It must not validate LASP syntax, completion, observable extraction, restart exactness, or execution.

The deterministic guard reads bounded regular non-symlink files, rejects ambiguous JSON and privacy/credential markers, refuses report overwrite, emits stable sorted JSON without timestamps or absolute paths, and never launches software. It opens every ancestor component relative to a stable directory descriptor with no-follow semantics, opens final inputs nonblocking before checking regular-file identity, and binds all same-directory evidence reads to that stable anchor. Reports are written through a retained staging descriptor and published by atomic hard-link create-if-absent after before/after inode, size, and content checks; replacement publication is forbidden. Exit codes are `0` plan pass, `2` blocked, `3` incomplete, and `4` internal error.

Structurally complete incomplete upstream inventories may feed later inventory stages only after one identity-checked raw-byte snapshot is validated for the development/no-positive/false-authorization invariants. Each downstream record binds the SHA-256 of those exact bytes; the self-computed canonical JSON fingerprint is only a consistency field and is not a trust root. Semantic equivalence after a raw-byte change does not preserve lineage.

Every report is `report_authenticity=unsigned-candidate-output`. Even a self-fabricated report with the full shape and a correct self-fingerprint remains unsigned and cannot become technical or scientific evidence through chaining. Evidence status requires an external trusted manifest or signature maintained outside this candidate's control.
