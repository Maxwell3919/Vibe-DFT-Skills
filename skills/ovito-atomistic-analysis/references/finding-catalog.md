# Stable finding catalog

Keep finding IDs stable within local schema version 0.1. A changed meaning requires a schema
revision and migration tests.

Inventory may complete with findings `TRAJECTORY_ATOM_COUNT_CHANGED`,
`TRAJECTORY_SPECIES_ORDER_CHANGED`, `TRAJECTORY_PROPERTY_SCHEMA_CHANGED`,
`TRAJECTORY_PBC_UNDECLARED`, `TRAJECTORY_PBC_CHANGED`, `TRAJECTORY_CELL_PRESENCE_CHANGED`, or
`TRAJECTORY_CELL_CHANGED`. Identifier-aware inventories may also emit
`TRAJECTORY_PARTICLE_IDENTIFIERS_CHANGED`, `TRAJECTORY_IDENTIFIER_SPECIES_CHANGED`, or the notice
`TRAJECTORY_STORAGE_ORDER_CHANGED_WITH_IDS`. Atom-count, unresolved mapping, property-schema, PBC, and cell-presence
drift block analysis readiness; variable-cell drift requires a decision. Request strict readiness
to turn non-ready state into an exit-2 boundary.

## Execution and provider blockers

`EXECUTION_NOT_AUTHORIZED`, `AUTHORIZATION_SCOPE_MISSING`, `AUTHORIZATION_SCOPE_MISMATCH`,
`EXECUTION_OUTPUT_REQUIRED`, `PIPELINE_NOT_EXECUTION_READY`, `PRO_EXECUTION_REFUSED`,
`EXECUTION_SOURCE_MISMATCH`, `OVITO_INVENTORY_MISMATCH`, `OVITO_DISTRIBUTION_MISMATCH`, `OVITO_VERSION_MISMATCH`,
`OVITO_UNAVAILABLE`, `SNAPSHOT_WRITE_FAILED`, `OVITO_PARTICLES_MISSING`,
`OVITO_CELL_INVALID`, `OVITO_PARTICLE_IDENTIFIERS_MISSING`, `OVITO_EXECUTION_FAILED`.

The probe reports `match`, `version-mismatch`, or `not-installed` and exits 3 unless matched.
`UNEXPECTED_INTERNAL_ERROR` exits 4 and certifies no result.

All blocked and internal envelopes carry the candidate lifecycle cap. No finding, plan, probe,
or bounded metadata run can set `promotion_authorized` or lifecycle `execution_authorized` true.
