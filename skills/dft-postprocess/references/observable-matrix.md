# Observable routing matrix

| Observable | Current route maturity | Required source evidence | Structured output | Critical validation |
|---|---|---|---|---|
| energy/SCF/relax | format-fixture-validated (`python.qe-text`, `python.vasp-text`) | main output plus run settings | JSON summary and CSV trace | completion, electronic/geometry status separation, units, step order |
| bands | format-fixture-validated (native QE/VASP parsers); synthetic-validated (comparison/projection panels and VASPKIT table adapter); external/package backends design-only | eigenvalues or explicit external table, k path, labels, declared energy transform/reference, optional aligned projection weights | long-form CSV/JSON, individual/comparison/projected-panel figures | band/k dimensions, reference, spin/SOC, path mapping, cross-table alignment; visual comparison does not establish scientific comparability |
| DOS/PDOS | format-fixture-validated (native QE/VASP parsers); external/package backends design-only | energy grid, total/projected channels | CSV/JSON | grid alignment, normalization, channel/site/orbital mapping |
| phonon | format-fixture-validated (`python.qe-phonon`); all VASP/CP2K/SIESTA and external routes design-only | q path/mesh, frequencies, explicit unit | CSV/JSON | q mapping, units, imaginary sign, direct vs interpolated evidence |
| EPC | format-fixture-validated (`python.qe-epc`); all other backends design-only | alpha2F/lambda, smearing, optional mode/q contributions | CSV/JSON | completeness, smearing alignment, explicit q-weight boundary |
| work function | format-fixture-validated (`python.grid`); no real-artifact receipt is registered | potential grid, explicit vacuum window, conversion, Fermi level | JSON and window table | source-matched reference, explicit window, no automatic plateau claim |
| charge/ELF/Bader | format-fixture-validated (`python.grid`, `python.bader-acf`); synthetic-validated (structure views); VESTA and other external tools design-only | grid, optional explicit linear-combination components, or ACF output | tabular/grid summary, crystallographic section, optional structure-isosurface project/image | grid shape/alignment, coordinate scale, field/isovalue units, plane/crop/color metadata, renderer provenance, electron closure |
| crystal structure views | synthetic-validated through ASE-backed constructed fixtures | ASE-readable structure; recorded boundary-image, radii/color and graphical-connectivity rules | top/side image, optional multi-structure overview, plot metadata | source hash, atom/site count, cell, display mapping; no bond-order claim |
| NEB | synthetic-validated (generic table) | caller-mapped image coordinates, energies, optional forces | CSV/JSON | image order, endpoints, reference energy; native formats unvalidated |
| optical | synthetic-validated (generic table) | caller-mapped complex dielectric components | CSV/JSON | monotonic eV grid, tensor mapping, broadening declaration; native formats unvalidated |

Maturity belongs to one `observable × code × backend` route. The code-level `maturity` field is a deprecated compatibility summary equal to the maximum of its backend routes; it must not be applied to every listed backend. Unsupported formats, missing immutable validation evidence, or missing dependencies produce `SCRIPT_GAP`, `TOOL_UNAVAILABLE`, or a blocked route, not invented results.
