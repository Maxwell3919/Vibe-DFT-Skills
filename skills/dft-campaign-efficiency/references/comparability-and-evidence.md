# Comparability and evidence

Records are directly comparable only when code, code version, task type, anonymized system class, atom count, and scientific protocol id match. The protocol must bind the scientific objective, model, convergence criteria, and accuracy acceptance.

Configuration ids may differ only in the efficiency choice being studied. If multiple numerical or model choices differ, classify the comparison as confounded and propose a controlled pilot.

Use only scientifically accepted records for positive recommendations. Failed/rejected records remain valuable for failure avoidance but cannot prove a faster accepted route.

Require at least two accepted observations for each compared configuration. Prefer medians, report sample counts and both core-hours and wall time, and retain contrary observations.
